## Validation de l'implémentation

- [ ] Suite contractuelle rejouée avec fixtures pi synthétiques (générateur commité, aucun extrait réel) : scénario « nouvel adaptateur » de la spec corpus.
- [ ] Idempotence : double `refresh` sans changement → flux inchangés octet par octet, zéro doublon ; fichier changé → relecture intégrale sans duplication (merge par id).
- [ ] Migration d'état : `state.json` plat → `sources.opencode` conservé, delta opencode nul, `sources.pi` peupli.
- [ ] Non-régression opencode : empreintes **par fichier** (`sdig fingerprint`) des shards opencode, avant/après la première ingestion pi — inchangées (l'empreinte globale change par construction : nouveaux shards, state, vue).
- [ ] Session vivante : ligne finale non terminée ignorée sans erreur, non acquittée, complétée à la passe suivante ; ligne terminée au JSON invalide → échec explicite sans corpus partiellement écrit.
- [ ] Fraicheur et registre : croissance de fichier → jeton pi changé, vue détectée en retard ; suppression compensée par création de même taille → jeton changé aussi ; sélection `all` sans aucune source → erreur ; chemin re-pointé → invalidation de la seule source concernée, signalée.
- [ ] Orphelins : `bashExecution` direct (sans appel antérieur) → sortie dans `raw/` sous `pi:<sessionId>:<id de ligne>`, aucun `rawRef` inventé, cas compté et partId signalé ; lisible par `sdig raw` explicite, absent du scan `--raw` (par conception, le scan ne couvre que les preuves référencées).
- [ ] Requête inter-sources sur fixtures dédiées : hits issus des deux sources, `--source` filtre exactement (titres compris), `--source pi --raw` ne lit que les preuves pi référencées, `sdig read pi:<uuid>` déroule, `sdig raw pi:<sessionId>:<toolCallId>` rend la preuve.
- [ ] `sdig status` : watermarks par source, absence signalée, pas d'erreur sur source par défaut absente.
- [ ] Tests existants (51 ciblés + suite complète) et `openspec validate --strict` ; pas de rejeu du jeu naturel gelé sans décision explicite.
- [ ] Documenter dans le README : corpus fusionné, nouvelles options, aplatissement des branches pi, perte associée.
